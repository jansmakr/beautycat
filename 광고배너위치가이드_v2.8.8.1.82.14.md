## 🎯 배너 우선순위 및 전략

### 1차 우선순위 (필수)
- **배너 #1**: 메인 상단 → 첫 화면 노출
- **배너 #2**: 폼 중간 → 시선 집중

### 2차 우선순위 (권장)
- **배너 #3**: 폼 하단 → 제출 전후
- **배너 #5**: 최하단 → 전체 소비 후

### 3차 우선순위 (선택)
- **배너 #4**: 사이드 → 데스크탑 상시 노출

## 🔧 실제 적용 예시

### Step 1: 샘플 배너 확인
```html
<!-- 현재 상태: 샘플 배너 -->
<div class="sample-ad-banner" style="background: linear-gradient(...)">
    <div class="text-white text-center">
        <p>🎯 광고 영역 #1</p>
    </div>
</div>
```

### Step 2: Google AdSense 코드로 교체
```html
<!-- 변경 후: AdSense 광고 -->
<ins class="adsbygoogle"
     style="display:block"
     data-ad-client="ca-pub-XXXXXXXXXX"
     data-ad-slot="XXXXXXXXXX"
     data-ad-format="horizontal"></ins>
<script>(adsbygoogle = window.adsbygoogle || []).push({});</script>
```

### Step 3: 직접 이미지 광고
```html
<!-- 또는: 직접 이미지 광고 -->
<a href="https://example.com" target="_blank">
    <img src="images/ads/banner-728x90.jpg" 
         alt="광고" 
         style="width:728px; height:90px; border-radius:8px;">
</a>
```
