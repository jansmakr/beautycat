## 🎯 프로젝트 개요

beautycat은 전국의 피부관리실과 고객을 연결하는 플랫폼입니다.

### 핵심 가치
- **투명한 가격 비교**: 여러 관리실의 견적을 한눈에 비교
- **간편한 예약 시스템**: 클릭 몇 번으로 예약 완료
- **신뢰할 수 있는 리뷰**: 실제 이용 고객의 후기
- **지역 기반 검색**: 내 주변 관리실 빠른 찾기

### 타겟 사용자
- **고객**: 피부관리를 원하는 일반 사용자
- **관리실**: 피부관리실 운영자 및 직원

## ✨ 주요 기능

### 🎨 v2.1.1 (2025-11-03) - 최신 업데이트

#### UI/UX 개선
- ✅ **검은색 테두리 통일**
  - 모든 버튼 테두리를 `2px solid #000000`으로 통일
  - 메인 페이지: "상담 및 견적신청", "로그인" 버튼
  - 로그인 페이지: 회원 유형 선택 버튼, 로그인 버튼
  - 회원가입 페이지: 회원 유형 선택 버튼, 회원가입 버튼
  - 일관된 hover 효과 (핑크 그라데이션 배경 + 검은색 테두리 유지)

- ✅ **로고/아이콘 배경 제거**
  - 로고 이모지 🐱: 배경, 테두리, 그림자 완전 제거
  - 고양이 아이콘 😺 (메인 페이지): 배경, 테두리, 그림자 완전 제거
  - 깔끔한 미니멀 디자인으로 개선

#### 모바일 최적화
- ✅ **터치 타겟 개선**
  - 모든 버튼: 최소 48px 높이 (iOS HIG 권장사항)
  - 입력 필드: 최소 48px 높이
  - 체크박스: 24px 크기로 확대

- ✅ **텍스트 가독성**
  - 본문 텍스트: 15px (모바일)
  - 입력 필드: 16px (iOS 자동 줌 방지)
  - 버튼 텍스트: 15px

- ✅ **반응형 레이아웃**
  - 네비게이션 바 모바일 최적화
  - 히어로 섹션 패딩 조정
  - 버튼 간격 및 크기 조정

#### 캐시 관리
- ✅ **_headers 파일 생성**
  - HTML 파일: 캐시 비활성화
  - CSS 파일: 1시간 캐시 (재검증 필요)
  - `mobile-optimized.css`: 캐시 비활성화
  - 보안 헤더 추가 (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection)

- ✅ **버전 태그 추가**
  - 모든 HTML 파일에 버전 메타 태그: `v=2.1.0-20251103-0440`
  - CSS 링크에 쿼리 파라미터: `?v=2.1.0-20251103-0440`
  - 캐시 무효화 타임스탬프 주석 추가
