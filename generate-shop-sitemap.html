📌 사용 방법

  1. "사이트맵 생성하기" 버튼을 클릭하여 XML 생성
  2. "다운로드" 버튼으로 shop-sitemap.xml 파일 저장
  3. 저장한 파일을 프로젝트 루트 폴더에 추가
  4. GitHub에 Push: git add shop-sitemap.xml
  5. 네이버 서치어드바이저 또는 Google Search Console에서 사이트맵 제출
  6. URL: https://beautyket.kr/shop-sitemap.xml
