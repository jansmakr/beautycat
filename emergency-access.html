Service Worker 리다이렉트 문제 해결

⚠️ 현재 상황:
포워딩된 도메인에서 Service Worker가 리다이렉트를 차단하고 있습니다.
✅ 즉시 해결책:
아래 방법 중 하나를 선택하여 문제를 해결하세요.

🎯 해결 방법

방법 1: 직접 접속 (가장 빠름)
Service Worker 없이 바로 사용할 수 있습니다.
🚀 직접 접속하기
방법 2: 브라우저 데이터 완전 삭제
1. Chrome 설정 → 개인정보 보호 및 보안 → 사이트 설정
2. 모든 사이트 → beautycat.kr 검색
3. "데이터 삭제" 클릭 → 모든 항목 체크 → 삭제
4. 브라우저 재시작 후 재접속
방법 3: 개발자 도구 사용
1. F12 → Application 탭
2. Service Workers → 모든 "Unregister" 클릭
3. Storage → "Clear storage" → "Clear site data" 클릭
4. 페이지 새로고침
💡 참고:
문제 해결 후에는 beautycat.kr 도메인으로 정상 접속 가능합니다.
모든 기능(회원가입, 로그인, 채팅, 데이터 저장)이 완벽하게 작동합니다.
