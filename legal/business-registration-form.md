## 🌐 **홈택스 온라인 신청 단계**

### **Step 1: 로그인**
```
1. hometax.go.kr 접속
2. 회원가입/로그인
3. 공인인증서 또는 간편인증 준비
```

### **Step 2: 신청 메뉴**
```
1. 신고/납부 클릭
2. 사업자등록신청 선택
3. 개인사업자 신규등록 클릭
```

### **Step 3: 정보 입력**
```
기본정보:
- 상호: beautycat
- 대표자명: [실제 이름]
- 사업장 주소: [실제 주소]

업종정보:
- 주업종: 63991 기타 정보서비스업
- 부업종: 47910 통신판매업

과세정보:  
- 면세사업자 선택 (매출 4,800만원 이하 예상)
- 개업일: 신청일
```

### **Step 4: 서류 업로드**
```
□ 신분증 사본
□ 임대차계약서 (해당 시)
□ 기타 필요 서류
```

### **Step 5: 신청 완료**
```
- 신청서 최종 확인
- 전자서명 또는 인증
- 신청 완료
- 접수번호 확인
- 3일 후 등록증 발급
```
